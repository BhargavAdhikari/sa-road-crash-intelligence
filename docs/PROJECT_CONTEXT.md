# Project Context

## Project Name

SA Road Crash Intelligence

## Purpose

Build a professional portfolio project using real-world data to develop practical skills in data analysis, GIS, statistics, SQL, Python, automation and technical communication.

## Primary Question

Where are serious road-crash hotspots in South Australia, and what patterns make those locations worth investigating?

## Decision-Support Goal

Identify locations and patterns that may help prioritise further investigation of serious road crashes rather than simply producing a map.

## Current Scope

The project has currently completed repository and project-structure setup.

The analysis itself has not yet started.

## Planned Core Technologies

Technologies will be introduced when required by the problem rather than taught separately.

Expected core tools include:

- QGIS
- Python
- SQL
- Git
- GitHub
