# Project Workflow

## Current Stage

Repository setup and project documentation.

## Current Repository Structure

- `AGENTS.md` — AI agent instructions
- `README.md` — public project overview
- `.gitignore` — files Git should not track
- `docs/` — context, decisions, workflow and data definitions
- `data/raw/` — untouched source data
- `data/processed/` — cleaned/transformed data
- `qgis/` — QGIS project files
- `python/` — Python scripts
- `sql/` — SQL scripts and queries
- `outputs/` — maps, charts, tables and deliverables

## Working Pattern

1. understand the problem
2. inspect the data
3. validate the data
4. analyse
5. verify results
6. interpret findings
7. document important decisions
8. commit verified milestones

The workflow will be expanded as actual processing stages are implemented.
