# SA Road Crash Intelligence

A professional data and GIS portfolio project investigating serious road-crash patterns and spatial hotspots in South Australia.

## Project Question

**Where are serious road-crash hotspots in South Australia, and what patterns make those locations worth investigating?**

## Project Goals

This project will demonstrate practical skills in:

- data acquisition and validation
- data cleaning
- exploratory data analysis
- practical statistics
- GIS and spatial analysis
- SQL
- Python
- automation
- interpretation and decision support
- Git and GitHub
- AI-assisted engineering with verification

## Repository Structure

- `data/raw/` — original downloaded source data, excluded from Git
- `data/processed/` — cleaned or transformed datasets
- `qgis/` — QGIS project files
- `python/` — Python scripts
- `sql/` — SQL scripts and queries
- `outputs/` — maps, charts, tables and final outputs
- `docs/` — project context, workflow, decisions and data definitions
- `AGENTS.md` — instructions for AI agents working with this repository
